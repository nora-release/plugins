# Vercel AI Gateway

Reach the models of many vendors through [Vercel AI Gateway](https://vercel.com/docs/ai-gateway) with one API key, billed to your Vercel team.

## Set up

1. Install the plugin.
2. Open **Settings → AI Providers**, add **Vercel AI Gateway**, and paste an AI Gateway API key from your Vercel dashboard.
3. Pick one of its models in the model picker.

Nora lists the models from Vercel AI Gateway's own model list, so new models show up without an update to this plugin.

## Details

| | |
| --- | --- |
| Plugin | `nora.vercel-ai-gateway` |
| Provider `vercel-ai-gateway` | OpenAI Chat Completions at `https://ai-gateway.vercel.sh` |
| Connects to | `ai-gateway.vercel.sh` |
| Runs code | No, Nora sends the requests itself |
