# Moonshot AI

Use Moonshot AI's Kimi models through the international [Moonshot AI platform](https://platform.moonshot.ai) with an API key.

## Set up

1. Install the plugin.
2. Open **Settings → AI Providers**, add **Moonshot AI**, and paste an API key from [platform.moonshot.ai](https://platform.moonshot.ai).
3. Pick one of its models in the model picker.

Nora lists the models from Moonshot AI's own model list, so new models show up without an update to this plugin.

## Good to know

For an account on the China platform (platform.moonshot.cn), install **Moonshot AI CN** instead.
