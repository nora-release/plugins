# UI Designer

Lets Nora's agent design or restyle user interfaces in the visual style of a well-known product.

## What it can do

- Design a page, app screen or component in a named style, such as Stripe, Vercel, Apple, Linear, Notion or Figma.
- Restyle an existing interface to match one of those styles.
- Choose a polished direction for you when you don't name a style.
- List the styles it knows.

Each style comes from a `DESIGN.md` reference bundled with the skill. It describes layout, color, type, spacing, components and motion. The references are inspiration, not official brand systems: the agent doesn't copy logos or trademarked assets.

## Try asking

- "Design a pricing page in the style of Stripe."
- "Restyle this settings screen to feel like Linear."
- "Which design styles can you use?"
