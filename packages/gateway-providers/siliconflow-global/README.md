# SiliconFlow

Use the open models hosted by [SiliconFlow](https://www.siliconflow.com) (international site) with an API key.

## Set up

1. Install the plugin.
2. Open **Settings → AI Providers**, add **SiliconFlow**, and paste an API key from [cloud.siliconflow.com](https://cloud.siliconflow.com).
3. Pick one of its models in the model picker.

Nora lists the models from SiliconFlow's own model list, so new models show up without an update to this plugin.

## Details

| | |
| --- | --- |
| Plugin | `nora.siliconflow-global` 1.0.0 |
| Provider `siliconflow-global` | OpenAI Chat Completions at `https://api.siliconflow.com/v1` |
| Connects to | `api.siliconflow.com` |
| Runs code | No, Nora sends the requests itself |
