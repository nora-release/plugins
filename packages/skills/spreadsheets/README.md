# Spreadsheets

Lets Nora's agent create, edit, analyze and visualize spreadsheets (`.xlsx`, `.csv`, `.tsv`).

## What it can do

- **Create** workbooks with real formulas, number formats and a clear layout.
- **Analyze** data: filter, group, pivot and compute metrics.
- **Edit** existing workbooks without breaking their formulas or references.
- **Visualize** data with charts and formatted tables in the sheet.
- **Check** its work by recalculating formulas and looking at each rendered sheet before handing it back.

## Try asking

- "Build a monthly budget with totals and a chart of spending by category."
- "Which products grew the most quarter over quarter in this file?"
- "Clean up this CSV and save it as a formatted Excel workbook."

## Requirements

The agent works with Python's `openpyxl` and `pandas`.
