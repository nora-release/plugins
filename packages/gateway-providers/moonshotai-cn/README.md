# Moonshot AI CN

Use Moonshot AI's Kimi models through the China [Moonshot AI platform](https://platform.moonshot.cn) with an API key.

## Set up

1. Install the plugin.
2. Open **Settings → AI Providers**, add **Moonshot AI CN**, and paste an API key from [platform.moonshot.cn](https://platform.moonshot.cn).
3. Pick one of its models in the model picker.

Nora lists the models from Moonshot AI's own model list, so new models show up without an update to this plugin.

## Good to know

For an account on the international platform (platform.moonshot.ai), install **Moonshot AI** instead.
